# 명령어 요약 (복사해서 쓰기)

설치 방법과 설명은 저장소 맨 위 [README.md](../README.md)를 보세요. 이 문서는 **명령어만** 모았습니다.
터미널은 VS Code 의 `Terminal > New Terminal` 입니다. 실습 폴더(그 안에 `windows`·`mac` 폴더가 보이는 맨 위 폴더)에서 실행하세요.

## 1. 설치 (한 번)

| | 명령 |
|---|---|
| **Windows** | `windows\install.bat` 더블클릭, 또는 터미널에서 `powershell -ExecutionPolicy Bypass -File windows\install.ps1` |
| **Mac** | `bash mac/install.sh` (`./install.sh` 는 권한 오류가 날 수 있습니다) |
| Windows 오프라인(Releases 의 zip) | `windows\setup.bat` 더블클릭, 또는 `powershell -ExecutionPolicy Bypass -File windows\setup.ps1` |

## 2. 설치 후 점검

VS Code 터미널 앞에 `(.venv)` 가 보일 때:

```
python check_env.py
```

`python` 을 못 찾거나 `(.venv)` 가 아니면 `.venv` 의 파이썬을 직접 부릅니다.

```powershell
.venv\Scripts\python.exe check_env.py
```

```bash
.venv/bin/python check_env.py
```

VS Code 에 `.venv` 연결: `Ctrl+Shift+P`(Mac 은 `Cmd+Shift+P`) → `Python: Select Interpreter` → `.venv`

## 3. 예제 실행 (예제11 폴더에서)

키 없이 먼저 화면만 보려면 MOCK 을 켭니다.

```powershell
$env:MOCK = "1"
```

```bash
export MOCK=1
```

앞은 Windows(PowerShell), 뒤는 Mac 입니다. 그 다음:

```
python -m streamlit run app.py
python -m uvicorn app:api --reload
```

- 채팅 화면: <http://localhost:8501> / API 문서: <http://127.0.0.1:8000/docs>
- `streamlit run` 이 아니라 **`python -m streamlit run`** 으로 씁니다(일부 PC 에서 `streamlit.exe` 가 보안 정책에 막힙니다).

## 4. git 으로 받기 / 업데이트

```
git --version
git clone https://github.com/sgustjd2/watsonx-day1-setup.git C:\edu\watsonx-day1-setup
git pull
```

Mac 은 받을 폴더를 `~/edu/watsonx-day1-setup` 으로 씁니다. git 이 없으면 설치하지 말고 ZIP 으로 받으세요.

## 5. 스크립트 없이 직접 설치 (스크립트가 막힌 PC)

python.org 에서 3.12 를 설치한 뒤(Windows 는 **Add python.exe to PATH** 체크):

```powershell
py -3.12 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.lock
```

```bash
python3.12 -m venv .venv
.venv/bin/python -m pip install -r requirements.lock
```

그 다음 `.env.example` 을 복사해 `.env` 를 만들고 2번(점검)을 합니다.

## 6. 문제가 났을 때

| 상황 | 명령 / 조치 |
|---|---|
| Mac 컴파일 오류 | `xcode-select --install` 후 `bash mac/install.sh` 다시 |
| 터미널 앞에 `(base)` (conda) | `conda deactivate` 후 새 터미널 |
| 패키지가 없다고 나옴 | 인터프리터를 `.venv` 로 선택한 뒤, 그래도 안 되면 `windows\install.bat` / `bash mac/install.sh` 다시 실행 |
| 설치를 처음부터 다시 | `windows\install.bat` / `bash mac/install.sh` 를 다시 실행(`.venv` 를 지우고 새로 만듭니다. `.env` 는 그대로) |
