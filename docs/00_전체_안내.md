## 10시 한 번 요약

- **Windows:** 실습 `windows` 폴더의 `install.bat` 더블클릭 (또는 `powershell -ExecutionPolicy Bypass -File windows\install.ps1`)
- **Mac:** 터미널에서 `bash mac/install.sh`
- uv가 파이썬 3.12와 라이브러리를 받아 `.venv`에만 설치합니다. 내 PC의 다른 파이썬·conda는 건드리지 않습니다. 인터넷이 필요하며, 막히면 Windows는 [오프라인 zip](https://github.com/sgustjd2/watsonx-day1-setup/releases/tag/v1)의 `windows\setup.bat`을 씁니다(Mac은 오프라인 미지원).
- 라이브러리 버전은 저장소 맨 위 `requirements.lock`에 고정되어 있습니다.
- 실행은 항상 `python -m streamlit run ...` / `python -m uvicorn ...` 형식입니다.
- conda/Anaconda는 설치하지 않습니다. 이미 있으면 그대로 두고 터미널에서 `conda deactivate` 후 진행합니다.

## lock 갱신 (관리자용, uv 필요)

```
uv pip compile requirements.txt --universal --python-version 3.11 -o requirements.lock
```
